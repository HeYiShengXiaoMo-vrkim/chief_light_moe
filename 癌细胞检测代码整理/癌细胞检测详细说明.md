# 癌细胞检测 (Cancer Cell Detection) 代码整理

## 功能概述
癌细胞检测模块是CHIEF系统的核心功能之一，专门用于在病理图像中自动检测和分类癌细胞。该模块支持多种癌症类型的检测，包括结肠癌、乳腺癌等。

## 技术特点
- 基于深度学习的多实例学习 (Multiple Instance Learning)
- 支持WSI (Whole Slide Image) 级别的病理图像分析
- 使用CHIEF预训练模型进行特征提取
- 二分类任务：正常 vs 癌症

## 主要文件说明

### 1. classification_eval.py - 主评估脚本
这是核心的评估脚本，主要功能包括：

**关键组件**:
- 模型加载: 使用预训练的CHIEF模型
- 数据处理: 加载病理图像特征数据
- 评估指标: AUC, F1-score, 精确率, 召回率, 准确率
- 结果保存: 预测结果和评估指标

**主要参数**:
- `--config_path`: 配置文件路径 (default: './configs/colon.yaml')
- `--dataset_name`: 数据集名称 (default: 'test_set')
- `--decimals`: 结果保留小数位数 (default: 4)

### 2. 配置文件 (configs/)

#### colon.yaml - 结肠癌检测配置
```yaml
General:
    result_dir: ./results/colon_Dataset_PT
    fold_num: 1
    seed: 2023

    model_name: CHIEF
    size_arg: small
```

#### breast.yaml - 乳腺癌检测配置

### 3. 数据处理 (datasets/)

#### BagDataset.py - 多实例学习数据集
- 实现MIL (Multiple Instance Learning) 数据加载
- 处理WSI级别的病理图像特征
- 支持包级别的标签分配

#### dataloader_factory.py - 数据加载器工厂
- 根据配置创建相应的数据加载器
- 支持不同数据集的统一接口

### 4. 模型 (models/)

#### CHIEF.py - 核心模型

## 输出结果

### 预测结果文件
- `results/{dataset}/evaluation/{dataset_name}/preds_0.csv`
  - 包含每个样本的预测概率和真实标签
  - 列: `label`, `prob_0`, `prob_1`

### 评估指标
脚本会自动计算并显示:
- **AUC** (Area Under Curve): ROC曲线下面积
- **F1-Score**: F1分数
- **Precision**: 精确率
- **Recall**: 召回率  
- **Accuracy**: 准确率

## 技术原理

### 多实例学习 (MIL)
- **包 (Bag)**: 一个WSI图像作为一个包
- **实例 (Instance)**: WSI中的每个patch作为实例
- **标签**: 包级别的标签 (正常/癌症)
- **假设**: 包为正当且仅当至少有一个实例为正

### 注意力机制
- 使用注意力权重聚合patch级别特征
- 自动学习哪些区域对分类最重要
- 提供可解释性的热力图

### 特征提取
- 基于预训练的CHIEF模型
- 每个patch提取高维特征向量
- WSI级别的特征通过MIL聚合得到

## 性能优化建议

### 硬件要求
- **GPU**: 建议8GB+显存 (6GB也可运行轻量化版本)
- **内存**: 建议16GB+ (8GB可运行轻量化版本)  
- **存储**: SSD推荐，加快数据读取

### 轻量化配置 (适用于6GB显存/8GB内存)

#### 1. 使用轻量化模型
```bash
# 结肠癌轻量化检测
python classification_eval_light.py --config_path configs/colon_light.yaml --dataset_name Dataset_PT

# 乳腺癌轻量化检测  
python classification_eval_light.py --config_path configs/breast_light.yaml --dataset_name DROID_breast

# 启用混合精度进一步节省内存
python classification_eval_light.py --config_path configs/colon_light.yaml --use_mixed_precision
```

#### 2. 轻量化配置参数
- `batch_size: 8` - 大幅减小批量大小 (原32→8)
- `max_bag_size: 512` - 限制每个包的patch数量
- `size_arg: "tiny"` - 使用最小模型 (768→64→1)
- `mixed_precision: true` - 启用混合精度训练
- `gradient_accumulation_steps: 4` - 梯度累积模拟大batch

#### 3. 内存优化技术
- **模型压缩**: 减少中间层维度 (256→128→64)
- **数据采样**: 限制每个WSI的patch数量
- **梯度累积**: 模拟大batch size而不增加内存
- **混合精度**: 使用FP16减少显存占用
- **动态内存清理**: 定期清理GPU缓存

### 参数调优
- `batch_size`: 根据GPU内存调整 (6GB建议≤8)
- `max_bag_size`: 控制每个包的最大patch数量 (建议≤512)
- `lr`: 学习率，影响收敛速度 (轻量化模型建议2e-4)
- `max_epochs`: 最大训练轮数 (轻量化版本30轮足够)
- `dropout`: 增加正则化防止小模型过拟合 (建议0.3)
