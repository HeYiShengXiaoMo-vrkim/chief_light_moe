## 🚀 轻量化特性

- **参数减少80%**: 768→64维度，大幅降低显存占用

- **dropout增强**: 0.25→0.3，防止小模型过拟合

### 内存优化  
- **批量大小**: 32→8 (减少75%显存占用)
- **patch限制**: 最多512个patch/WSI
- **混合精度**: FP32→FP16，减少50%显存
- **梯度累积**: 模拟大batch效果
- **动态清理**: 自动释放GPU缓存

### 数据优化
- **预加载控制**: 小数据集内存预加载
- **采样策略**: 随机采样大型WSI
- **文件格式**: 支持.pt/.h5/.npy多种格式

## 🔧 配置详解

### colon_light.yaml 关键参数
```yaml
Model:
    size_arg: tiny          # 使用最小模型
    dropout: 0.3           # 增强正则化

Train:
    batch_size: 8          # 小批量
    max_bag_size: 512      # 限制patch数量
    mixed_precision: true  # 混合精度
    gradient_accumulation_steps: 4  # 梯度累积
```

### 内存控制策略
1. **动态采样**: WSI>1000 patches时随机采样
2. **定期清理**: 每10个batch清理GPU缓存
3. **权重过滤**: 只加载匹配的预训练权重
4. **禁用梯度**: 推理时关闭梯度计算

## 📈 优化建议

### 进一步减少显存 (如果4-6GB还不够)
1. **减小max_bag_size**: 512→256→128
2. **降低特征维度**: 在配置中修改
3. **使用CPU推理**: 速度慢但显存占用为0
4. **分批处理**: 拆分大的WSI

### 提升性能
1. **SSD存储**: 加快数据读取
2. **增加worker**: num_workers=4 (如果内存充足)
3. **预加载数据**: 小数据集可以预加载到内存
4. **CUDA优化**: 设置CUDA_LAUNCH_BLOCKING=0

### 常见问题解决

#### 1. 仍然显存不足
```yaml
# 进一步减小配置
Train:
    batch_size: 4
    max_bag_size: 256
```

#### 2. 内存不足
- 关闭浏览器和其他程序
- 设置虚拟内存
- 减小num_workers

#### 3. 速度太慢
- 使用SSD存储
- 开启混合精度
- 预加载小数据集

#### 4. 精度下降
```yaml
# 调整正则化
Model:
    dropout: 0.2  # 减小dropout
    
Train:
    lr: 1.5e-4   # 降低学习率
```
